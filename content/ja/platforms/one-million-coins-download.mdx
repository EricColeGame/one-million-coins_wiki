## One Million Coins のシステム要件とプラットフォーム対応

これは要求の厳しいゲームではありません。金庫はフォトリアルな見せ場ではなく、様式化されたカートゥーン調の 3D 空間であり、要件もそれを反映しています。それでも、最低要件と推奨要件には意味のある違いがあるため、購入前に自分のハードウェアと照らし合わせる価値があります。

| コンポーネント | 最低 | 推奨 |
|---|---|---|
| OS | Windows 10（64ビット） | Windows 10 / 11（64ビット） |
| プロセッサー | Intel Core i5-8400 または AMD Ryzen 5 2600 | Intel Core i7-9700K または AMD Ryzen 5 3600 |
| メモリ | 8 GB RAM | 16 GB RAM |
| グラフィックス | NVIDIA GTX 1060 6 GB / AMD RX 580 8 GB | NVIDIA RTX 2060 / AMD RX 6600 |
| DirectX | バージョン 11 | バージョン 11 |
| ストレージ | 空き容量 2 GB | 空き容量 2 GB |

仕様表だけでは分からない実用的な注意点がいくつかあります。

- **メモリの差が本当の分岐点です。** 8 GB から 16 GB への増加は、2 つのティア間で最大の違いです。最低要件に近い場合は、長時間のプレイ前にバックグラウンドアプリを閉じましょう。
- **すべて DirectX 11** なので、記載された VRAM 容量を満たしていれば、古い GPU が自動的に締め出されることはありません。
- **Steam Deck 対応は「不明」と記載されています。** 携帯機でのサポートを前提にしないでください。ストアはどちらとも検証していません。
- **言語サポートは英語のみです。** ストアには英語のインターフェースと字幕が記載されており、表に他の言語オプションはありません。

あなたのマシンが最低ティアをクリアしていれば、One Million Coins のダウンロードは問題なくインストールされ、動作します。推奨ティアをクリアしていれば、余裕があります。

## ゲームプレイループの実際の仕組み

アップグレードシステムを取り除けば、One Million Coins は非常にシンプルなアイデアを大きな勢いで実行したものです。あなたはちょうど 1,000,000 枚のコインが入った地下金庫に、空のポケットと素手だけを持って放り込まれます。その後はすべて加速です。

| 段階 | やっていること | アンロックされるもの |
|---|---|---|
| 1. 手作業でのすくい上げ | 手でコインを拾う | 最初の預け入れ |
| 2. 運搬と預け入れ | 金を預入ステーションまで運ぶ | 使える資金 |
| 3. ツールアップグレード | より良い回収装備を購入する | より速い収集 |
| 4. 容量アップグレード | ポーチとバックパック | 1回の運搬量増加 |
| 5. スキルツリーへの投資 | 移動、リーチ、速度、容量に使う | 複利的な効率化 |
| 6. インフラの復旧 | リフト、コンベア、預入ステーションを再建する | 自動運搬 |
| 7. 終盤のツール | コインの波を引き寄せる高性能装備 | 本格的なゴールドラッシュ |

リズムは古典的なインクリメンタルゲームの魅力です。毎回の運搬は前回より少し速くなり、「遅いと感じる」状態と「自分は金収集マシンだ」という状態の差は、思っているより早く縮まります。金庫は有限でコインの数も固定されているため、本物のゴールラインも存在します。無限の数字を追うのではなく、バンカーを完全に空にすることが目標です。

ファーストパーソンゲームとしては珍しく、非常に身体的な操作感があります。プログレスバーを見るのではなく、実際に荷物を運ぶのです。これが、One Million Coins のダウンロードを、影響を受けたブラウザベースのインクリメンタルゲームと一線を画す点です。

## 進行、スキルツリー、金庫攻略を速めるためのヒント

ここでの奥深さは、**7 つのアップグレードパスに広がる 250 以上のノードからなるスキルツリー** から来ています。ストアページでは、改善される大まかな領域として、移動、リーチ、収集速度、ツールの強さ、運搬容量、預入速度が挙げられています。

| アップグレード領域 | 改善されるもの | 重要な理由 |
|---|---|---|
| 移動 | 金庫内を移動する速さ | 山と預入ステーション間の無駄時間を削減 |
| リーチ | コインを掴める距離 | 位置調整の移動を減らす |
| 収集速度 | すくい上げる速さ | 他のすべてのアップグレードを直接倍増 |
| ツールの強さ | ツールが 1 回の動作で引き寄せる量 | ツールが強くなるにつれて生産量が拡大 |
| 容量 | 運べる量 | 1 回の運搬あたりの往復回数を削減 |
| 預入速度 | 金が資金に変換される速さ | ステーションでのボトルネックを解消 |

ノードが多いため、あれこれ手を広げすぎてしまいがちです。いくつかの習慣が役立ちます。

- **買い物の前に預け入れを。** 支出は預け入れ済みの資金からのみ行われるため、半分しか入っていない袋よりも、完了した預け入れが常に優先です。
- **まず容量、次に速度。** 序盤に失う時間のほとんどは往復の移動です。より大きな積載量は、すくい上げ速度を上げるよりも早くそれを縮めます。
- **すぐに再投資を。** 未使用の資金を抱えていても何も起こりません。このループは絶え間ない回転に報います。
- **利用可能になったらインフラを復旧しましょう。** リフトやコンベアは、小さなステータス上昇よりも 1 回の攻略の形を大きく変えます。
- **自分のペースでプレイしましょう。** ストアでは、自分のペースでプレイ可能、いつでもセーブ可能と明記されているため、離席してもペナルティはありません。

One Million Coins のダウンロードを計画している人にぜひ伝えておきたいことがもう 1 つあります。このゲームはアクセシビリティ機能として、クイックタイムイベントなし、カスタム音量コントロール、ステレオサウンドなどが記載されています。設計上、低プレッシャーなゲームです。

## FAQ

**無料の One Million Coins ダウンロードはどこかにありますか？**
いいえ。公式リリースは有料の Steam 版のみで、定価は $2.49、ローンチ割引により導入キャンペーン期間中は $1.99 になります。無料完全版を提供しているサイトは承認されておらず、公式ストアページにデモや無料クライアントは記載されていません。

**One Million Coins をクリアするのにどのくらいかかりますか？**
開発者は短く集中した体験と説明しており、ほとんどのプレイヤーは約 2 時間で金庫を攻略できると想定されています。1,000,000 枚のコインをすべて集め、16 個の実績をすべて解除するには、当然もっと時間がかかります。

**自分の PC で動作しますか？**
64 ビット版 Windows 10、8 GB RAM、そして GTX 1060 / RX 580 クラスの GPU があれば最低要件を満たします。推奨環境を目指すなら、16 GB RAM と RTX 2060 または RX 6600 を用意してください。ストレージ要件は最小で 2 GB です。

**One Million Coins のダウンロードは Steam Deck で動作しますか？**
Steam は現在、Deck 対応を「不明」と記載しており、プレイ可能とも非対応とも検証されていません。携帯機でのプレイを考えている場合は、購入前に [One Million Coins の公式 Steam ストアページ](https://store.steampowered.com/app/5258340/One_Million_Coins/) で最新状況を確認してください。
