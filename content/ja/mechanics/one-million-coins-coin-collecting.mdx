## One Million Coins とは実際どんなゲームか

One Million Coins は、ちょうど 1,000,000 枚の金貨が詰まった地下金庫に放り込まれ、それを動かす手段は自分の素手しかない、というゲームです。One Million Coins のコイン収集の本当の魅力は山の大きさではありません。運搬分を預金して利益を再投資していくうちに、ゆっくりとした手作業が次第に自動化されたゴールドラッシュへと変わっていく様子を眺められることにあります。

何時間も無駄にせずにバンカーを空にしたいなら、コアループ、ツール、スキルツリーがどう噛み合っているかを理解する必要があります。まさにそのために書かれたのが、この One Million Coins コイン収集ガイドです。

これはソロ開発者兼パブリッシャーの ShoXx による、短編の一人称インクリメンタルゲームで、2026年10月13日にリリースされました。終わりのない放置ゲームとは違い、ここでの金庫は有限で数え切れます。最後の1枚がバンカーを出たとき、そこには本当のゴールラインがあります。

## コイン収集のコアループを順を追って

One Million Coins のプレイは毎回、同じ5拍子のリズムで進み、購入するすべてのアップグレードはその拍のどれかを短縮するために存在します。

| 段階 | やること | なぜ重要か |
| --- | --- | --- |
| 収集 | 素手またはツールで山からコインをすくう | 生の金は財布ではなく金庫の中にある |
| 運搬 | 積荷を預入ステーションまで運ぶ | 積載量が1回の往復の価値を決める |
| 預入 | 積荷を使える資金に変換する | 預け入れた金だけがアップグレードを買える |
| アップグレード | 資金をツール、バッグ、スキルノードに使う | 購入のたびに次の往復が速くなる |
| 拡張 | バンカーの設備を復旧し、より深く掘る | 新しい空間と速いルートが開ける |

ループを理解することが重要なのは、ここでの難所が戦闘や反射神経ではなく、物流だからです。コインは口座ではなく金庫に湧き、金が役に立つ唯一の方法は、それを物理的に預入ステーションまで運んで資金に変えることだけです。

この一つのルールが、あなたが下すほぼすべての判断を説明してくれます。往復が短すぎると感じたら、必要なのは積載量です。すくうのが遅いと感じたら、必要なのはより良いツールです。収集より歩いている時間の方が長いなら、必要なのは移動とリーチです。ループをパイプラインとして読むこと——収集、運搬、預入、アップグレード、拡張——が、間違ったタイミングで間違ったものを買うのを防いでくれます。

時間が経つにつれ、ループは圧縮されていきます。序盤は30秒かかっていた往復が、ツールとスキルノードが積み重なるとほぼ一瞬のコインの波になります。その加速こそが、ゲーム全体の報酬構造なのです。

## ツール、積載量、そして250以上のノードを持つスキルツリー

### 素手から金を集める機械へ

最初は素手でコインをすくい始めますが、これは意図的に退屈に作られています。次にポーチ、そしてバックパック、さらに一動作でより多くの量を引き寄せる、徐々に強力になるツールが続きます。運搬は作業の半分を占めるため、積載量はそれ自体が独立したアップグレード経路になっています。

| フェーズ | 典型的な装備 | 何が変わるか |
| --- | --- | --- |
| 開始 | 素手 | わずかなすくい取り、絶え間ない往復 |
| 序盤 | ポーチ | 1回の往復でより多くのコイン、戻る回数が減る |
| 中盤 | バックパックとアップグレード済みツール | より大きな積荷と速い収集 |
| 終盤 | 高性能ツール | 一度に大量のコインを収集 |
| エンドゲーム | 完全にアップグレードされた運用 | 金庫が自分専用のゴールドラッシュに |

終盤こそがこの幻想が実現する場所です。高性能ツールが大量のコインを一掃し、金庫は退屈な雑用から自ら餌を供給する機械へと変わります。ペース配分は、その転換点に到達することを中心に組み立てられています。

### 250以上のノードを持つスキルツリーのどこに投資するか

スキルツリーは One Million Coins で最も奥深いシステムで、7つのアップグレード経路に250以上のノードが広がっています。確認されているアップグレードカテゴリには、移動、リーチ、収集速度、ツール強度、積載量、預入速度が含まれ、まさに5拍子のループに対応するステータスばかりです。

| アップグレードの焦点 | 何が向上するか | いつ投資すべきか |
| --- | --- | --- |
| 移動 | 金庫を横断する速さ | 序盤——移動時間は隠れた税金 |
| リーチ | コインを掴める距離 | 山が広がってきたとき |
| 収集速度 | 1動作あたりの毎秒コイン数 | 常に。決して無駄にならない |
| ツール強度 | 現在の装備のパワー | 新しいツール段階に移る前に |
| 積載量 | 1回の往復で運べる量 | 往復が短すぎると感じるたびに |
| 預入速度 | 積荷が資金に変わる速さ | 預入がボトルネックになったとき |

ゲームが短いため、すべてを快適に最大化することはできません。ツリーは、今あなたを遅くしているものに対する答えの集合だと考えてください。絶えず往復しているなら、移動と積載量が効きます。永遠に立ち止まってすくい続けているなら、収集速度とツール強度が勝ちます。

快適さに関する補足を1つ。いつでもセーブでき、ゲームは自分のペースで遊べるよう明示的に設計されているので、ツリーを一気に完成させるプレッシャーはありません。

## バンカーの復旧とより深く掘ること

One Million Coins の進行は装備だけではなく、金庫そのものにも関わります。資金を預け入れるとバンカーの設備を修理・復旧でき、それによって金が山から口座へどれだけ効率よく移動するかが変わります。

| 設備 | 運用における役割 |
| --- | --- |
| 預入ステーション | 運んだコインを使える資金に変換する |
| カーゴリフト | 金と資材をバンカー内で垂直に移動させる |
| コンベア | 長距離のコイン移動を自動化する |
| バンカーシステム | より深い区画を復旧し、新しい採掘スペースを開く |

設備のアップグレードは、このゲームで自動化に最も近いものです。カーゴリフトとコンベアがあればコインはあなたなしで移動し、バンカーのより深い区画を復旧すると、同じ山が増えるだけでなく新しい採掘スペースが解放されます。

より深く掘ることは、ペース配分のレバーでもあります。自分のペースで新しいエリアへ進めますが、それを一気に進める方が同じ場所を延々と掘るより優れている傾向があります。新しい設備は通常、積載量ノードをもう1つ増やしたときのわずかな利益を上回るのです。

## 金庫をより速く空にするコツ

| コツ | なぜ効果的か |
| --- | --- |
| 積荷は毎回すぐ預け入れる | 未預入の金は死重。資金は使って初めて複利で増える |
| 積載量と速度のバランスを取る | 満杯にできない巨大なバックパックは無駄なアップグレード |
| 純粋なパワーより先に移動を上げる | 序盤最大の静かな時間の浪費は移動時間 |
| 貯めるのではなく再投資する | 遊んでいる資金は収集速度に何もしない |
| 深部へは一気に押し進める | 新しい設備は同じ山を掘り続けるより優れている |
| 1つではなく7つの経路を見る | 偏ったビルドよりバランスの取れたビルドの方が金庫を早く空にできる |

より広い習慣もいくつか重要です。早めに、そして頻繁に預け入れましょう。ツールに変えた預入は、まさに次の往復から効果を発揮し始めます。それを満たす収集速度が備わる前に、積載量へ過剰投資しないこと。そしてゴールラインを忘れないこと——金庫にはちょうど1,000,000枚のコインがあるので、すくうたびに終わりへ向けた永続的で測定可能な前進になります。

## FAQ

### 100万枚のコインを全部集めるのにどれくらいかかりますか？

開発者は One Million Coins を短く集中した体験として位置づけており、ほとんどのプレイヤーはおよそ2時間で金庫を攻略できるはずです。実際の時間は、ツールとスキルノードにどれだけ効率よく投資するかによります。ループを回し続ける集中したビルドは、ポイントを薄く広げたビルドよりも明らかに早く終わります。

### One Million Coins のコイン収集は難しいですか？

反射神経の意味では難しくありません。クイックタイムイベントはなく、いつでもセーブでき、自分のペースで遊べるように設計されています。ここでの「難しさ」は最適化です。つまり、単に一番強そうなものを買うのではなく、今のボトルネックを取り除くアップグレードはどれかを決めることです。

### コントローラーで遊べますか？

はい——Xbox コントローラーに対応しており、ゲームはシングルプレイヤーで、Steam クラウドセーブ、実績、リーダーボードを備えています。Steam Deck の互換性はローンチ時点では不明とされていたため、携帯機でのプレイを計画する前に確認してください。

### 動かすのに強力な PC が必要ですか？

いいえ。最低スペックは Intel Core i5-8400 または AMD Ryzen 5 2600 相当、8 GB の RAM、GTX 1060 または RX 580、ストレージ 2 GB です。推奨スペックは i7-9700K または Ryzen 5 3600、16 GB の RAM、RTX 2060 または RX 6600 に上がります。一人称インクリメンタルゲームとしては控えめな要件で、ほとんどの現代のゲーミング PC なら問題なく One Million Coins を動かせるでしょう。
