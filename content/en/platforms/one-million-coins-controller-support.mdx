## Native Support vs. Steam Input Mapping

There are two very different ways a PC game can "support" a controller, and knowing the difference saves a lot of frustration.

**Native support** means the game reads your gamepad directly. On-screen prompts switch to A/B/X/Y, menus respond to the D-pad or stick, and the camera moves with the right thumbstick without any middleware.

**Steam Input translation** means Steam converts your pad's inputs into keyboard and mouse commands. It works, but the game still thinks you're on a keyboard — so prompts keep showing key letters, and some actions may feel slightly off until you tune them.

For One Million Coins, the store page doesn't state which approach is used. A quick test settles it: launch the game with your controller connected and watch the prompts. If you see keyboard letters, Steam is translating. If you see button icons, the game supports the pad natively.

Either way, Steam Input is your safety net. Right-click the game in your library, open **Properties → Controller**, and you'll find a full configurator with community layouts you can apply in seconds.

## How to Set Up a Controller for One Million Coins

If the game doesn't recognize your pad immediately, this sequence resolves the vast majority of cases.

| Step | Action | Why it matters |
|---|---|---|
| 1 | Connect the controller via USB or Bluetooth and confirm it in Windows | Rules out driver and pairing issues before blaming the game |
| 2 | In Steam, enable Steam Input for One Million Coins | Forces Steam to translate inputs if native support is missing |
| 3 | Launch the game and test movement, camera, and grab | Identifies which actions are bound and which are dead |
| 4 | Open the Steam Input configurator and bind missing actions | Covers grab, deposit, interact, and menu navigation |
| 5 | Save the layout as a personal template | Keeps your bindings intact across updates |

A sensible starting layout for a first-person collector looks like this: left stick for movement, right stick for camera, right trigger for grabbing or scooping coins, left trigger for interacting with the deposit station, and face buttons for menus. If the camera feels twitchy, lower sensitivity in the in-game options first and adjust the deadzone in Steam Input second.

## FAQ

**Does One Million Coins have controller support?**
The Steam store page lists Xbox Controllers among its input notes, which indicates gamepad play is recognized. However, Steam's formal "Full controller support" badge isn't displayed, so One Million Coins controller support is best described as acknowledged but not officially rated. Testing after launch is the fastest way to confirm behavior on your specific pad.

**Is One Million Coins controller support confirmed for Steam Deck?**
No. Steam Deck compatibility is currently listed as Unknown, meaning Valve hasn't verified it. Given the low system requirements and 2 GB install size, it's likely to run, but "likely" isn't "verified." Check the store page for updates or test it yourself during the refund window.

**Can I remap buttons if the default layout feels wrong?**
Yes. Even without official bindings, Steam Input lets you assign every action to any button, tune deadzones, and save a personal template. This is the most reliable workaround if One Million Coins controller support doesn't cover every menu action out of the box.

**Should I use a controller or keyboard and mouse?**
For the collecting grind, a controller is more comfortable and better suited to couch or handheld play. For heavy skill-tree planning across the 250-plus node upgrade paths, mouse and keyboard is faster. Many players will end up using both depending on what they're doing in the vault.
